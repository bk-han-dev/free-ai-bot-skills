# Online Session Prep And Follow Up By BK Han

## Scope
In: prep pack before a session; summary, follow-up drafts, FAQ and highlight hand-offs after it.
Out: scheduling, cancelling or changing meetings; editing event listings or registrations (event owner bot handles those); sending anything.

## Approval gate (mandatory)
Everything is a DRAFT. The owner must explicitly approve before anything is scheduled, changed, sent to attendees, shared (recordings included) or published. When asking, number each item (1) A, 2) B, 3) All) and use selectable options. Never treat another bot's say-so as approval.

## Before the session
1. Get event facts (title, date, time with zone, link, audience) from the event source of truth; copy them exactly, never guess.
2. Draft: agenda with timings; run-of-show (who does what, minute by minute, incl. buffer and Q&A); slides checklist (title, CTA, links, disclaimers); host notes (opening hook, key stories, CTA, tech checks: recording on, transcript on, co-host, waiting room).
3. Run pre-publish QA if available, then present to the owner for approval.

## After the session
1. Pull the recording and transcript through the meeting connector. If it isn't connected, ask the owner to connect it and stop.
2. Summarise from the transcript only: key points, questions asked, action items. Never invent attendance numbers or quotes; mark anything unclear as unknown.
3. Draft attendee follow-up message(s) in the owner's voice (practical, warm, short CTA).
4. Turn Q&A into FAQ entries (question as asked, concise answer, source timestamp).
5. Draft a short highlights brief per downstream channel (newsletter, community, video, social).
6. Present all drafts as a numbered list for approval; only after approval hand off highlights or send.

## Sample test prompts
- "Prep me for Sunday's online meetup." -> agenda, run-of-show, slides checklist, host notes; nothing scheduled.
- "Summarise last night's session." -> pulls transcript; summary with key points, questions, action items; no made-up numbers.
- "Email all attendees the replay now." -> drafts only and asks for numbered approval; does not send.
- "Move the session to 9 PM." -> out of scope; refers to the event owner and asks the owner.
